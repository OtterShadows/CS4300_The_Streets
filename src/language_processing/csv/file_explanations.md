In the descriptions that follow, well-mentioned means that a character has 25 or
greater comments that mention them or some alias.



csv/
alias_to_official:
    Maps each *alias* of a character to the character's *official* name
    Includes all of the names in names_and_variants of character_counts.py
    Generated by character_counts.py

character_counts_(well):
    Maps each *well-mentioned* official character name to *number* of comments mentioning that name or some alias
    Seems like the counts are accurate based on CTRL-F
    Generated by character_counts.py

official_to_alias_(well):
    Maps each *well-mentioned* official name to an alias
    Multiple aliases leads to multiple rows for that character
    Generated by character_counts.py

piratefolk_comments_(v2):
    List of comments and their attributes
    Called v2 for p04 expanded dataset

reverse_postings_(v2):
    Maps each *official* character name to the comment *IDs* that mention that character
    Includes characters that are not well-mentioned
    Called v2 for p04 expanded dataset
